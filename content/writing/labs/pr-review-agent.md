An experiment brief. This page does not describe a shipped tool.

## The experiment

Explore whether a small review assistant can identify a narrowly defined class of issues and provide enough context for a developer to check its findings.

## First iteration

1. Choose one kind of issue to look for.
2. Assemble a small set of example changes.
3. Record expected findings before running the assistant.
4. Compare its output with those expectations.
5. Keep a log of false positives and missed issues.

## Open questions

What information does the reviewer need? Which findings are useful enough to interrupt someone? When should the assistant say nothing?
